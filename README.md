# Data Extraction in ETL - Assignment

This repository contains my assignment work on Data Extraction in ETL.

The assignment covers different types of data sources, data extraction,
CSV and Excel extraction, relational database extraction, extraction
challenges, APIs, enterprise-level data extraction, and handling large
CSV files.

## Topics Covered

- Types of Data Sources in ETL
- Data Extraction and ETL Pipeline
- CSV vs Excel
- Relational Database Extraction
- Challenges in Data Extraction
- APIs and Real-Time Data Extraction
- Enterprise-Level Database Extraction
- Large CSV File Extraction

## Assignment Questions

### Question 1
Describe different types of data sources used in ETL with suitable examples.

### Question 2
What is data extraction? Explain its role in the ETL pipeline.

### Question 3
Explain the difference between CSV and Excel in terms of extraction and ETL usage.

### Question 4
Explain the steps involved in extracting data from a relational database.

### Question 5
Explain three common challenges faced during data extraction.

### Question 6
What are APIs? Explain how APIs help in real-time data extraction.

### Question 7
Why are databases preferred for enterprise-level data extraction?

### Question 8
What steps should an ETL developer take when extracting data from large CSV files (1GB+)?
